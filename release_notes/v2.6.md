# v2.6: Everything visible in the editor

**Download:** grab **JohnsBeerRun-v2.6.zip** below, unzip it, and import `project.godot` in Godot 4.3+ (4.7 works; let it upgrade the project if it asks).

### Changes
- **`scenes/main.tscn` now shows the whole game in the editor.** Before, the world and characters were only loaded once the game started, so the editor looked empty. Now these are all placed in the scene:
  - **The world:** the cabin, the neighborhood, the town, the Fuel Stop and the terrain.
  - **The 8 street lamps,** under World → Streetlights. You can move, duplicate or delete them, and the light, fill and glow go with each lamp.
  - **John, the M1, the visitor and the Glock** on the side table.
- **The game plays exactly as before.** The scripts now use the objects already in the scene instead of creating their own.
- **README:** new section, "Editing in the Godot editor".
