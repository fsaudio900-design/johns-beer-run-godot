# v2.4: Outdoor lighting

**Download:** grab **JohnsBeerRun-v2.4.zip** below, unzip it, and import `project.godot` in Godot 4.3+.

### Changes
- **Street lamps:** all 8 now give off real light: the 3 around the cul-de-sac and the 5 along Main Street. The web version only lit 3 of them.
  - Each one casts a warm sodium-orange pool onto the road and sidewalk, with proper shadows.
  - Each has a soft fill light and a glowing halo around the lamp head.
- **Moonlight:** stronger and bluer. Once John steps outside, the shadowed areas brighten, so the streets, lawns and houses stay readable between the lamps. The cabin interior is unchanged.
- **Effects:** the muzzle flash, sparks and lamp glows use a new glow texture, so they can no longer render as square boxes on some graphics cards.
