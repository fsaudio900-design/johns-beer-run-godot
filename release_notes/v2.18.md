# v2.18: Dialogic installed

**Download:** grab **JohnsBeerRun-Setup-v2.18.exe** (installer) or **JohnsBeerRun-Windows-v2.18.zip** below.

### New: the Dialogic 2 dialogue system
- The Dialogic 2.0 Alpha 20 plugin is now installed in the project (`addons/dialogic`) and enabled. It is a visual editor for conversations, characters and branching choices, built for Godot 4.5 and later.
- Open the project in Godot 4.7 and you'll find the **Dialogic** tab at the top of the editor, next to 2D, 3D and Script. Use it to write timelines (conversations), set up characters and pick a text box style.
- The `Dialogic` autoload is registered, so the game can start any timeline from code with `Dialogic.start("timeline_name")`.
- Dialogic's default "advance" input is set up: Enter, Space, X, left click or the A button.

### Unchanged
- No in-game conversations use Dialogic yet. Ben and the rest still use the game's own subtitles, so gameplay is the same as v2.17.

Built and tested on Godot 4.7.2.
