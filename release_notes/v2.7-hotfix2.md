# v2.7 hotfix 2: Glock size fixed

Same version (v2.7). Bug fix only.

**Download:** grab **JohnsBeerRun-v2.7-hotfix2.zip** below, unzip it, and import `project.godot` in Godot 4.3+.

### Fix
- **The Glock was enormous.** Newer Godot versions (like your 4.7) import the gun's FBX file at a different scale than 4.3 does. The game now uses a saved copy of the gun model that loads at the same size in any Godot version, so it's the real Glock 19 length (18.7 cm), both on the side table and in John's hand.
