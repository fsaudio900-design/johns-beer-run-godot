# v2.9: Pause menu and the Windows build (stage 8, port complete)

The Godot port is complete. Everything from the web game is in, plus the Godot upgrades.

**Download:**
- **JohnsBeerRun-Setup-v2.9.exe** is the Windows installer. It needs no admin rights and replaces the old web-version install.
- **JohnsBeerRun-Windows-v2.9.zip** is the game as a single .exe. Unzip it and play.
- **JohnsBeerRun-v2.9.zip** is the Godot project (import `project.godot` in Godot 4.3+).

### New
- **Pause menu:** press **Esc** or **P**. Clicking away from the window also pauses.
  - Everything freezes and the sound goes quiet.
  - Options are **Continue**, **Restart**, **Exit to Main Menu** and **Exit to Desktop**. The last three ask you to select again to confirm.
  - W/S or the mouse to choose, Enter to select, Esc to resume.
- **A native Windows game:** a single JohnsBeerRun.exe built by Godot, with no browser underneath.
- **The installer, rebuilt around the Godot game.**
  - It keeps the same look: the Cessna title art, and it detects an installed version so you can update, reinstall or replace.
  - It adds Start menu and desktop shortcuts with the game icon, and an entry under Settings → Apps.
  - It installs per user with no admin rights, and can uninstall.
- **Automatic Windows builds:** every future release builds the Windows game and installer on GitHub automatically.
